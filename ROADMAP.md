# Roadmap

Version 1.0.0 was published on 9 October 2026. Future items have no promised
date or order.

## Shipped in 1.0.0

- [x] Queue for text, images, and files; sequential paste; reorder, delete, clear
- [x] Combine and Paste for text with a chosen separator
- [x] Settings: rebindable shortcuts, seven languages, Launch at Login
- [x] 14-day trial and license activation, validation, and deactivation
- [x] Automatic updates with Sparkle
- [x] Continuous integration on every pull request
- [x] Website in seven languages with direct download and checkout
- [x] Developer ID signing and notarization of the release build
- [x] First signed release published on the website and in [Releases](../../releases)
- [x] Signed Sparkle feed published; full 0 → 1 update verified with a local feed

## Later validation and improvements

- [ ] Paid purchase and refund flow; deferred by the owner for the first release
- [ ] Full update through the production HTTPS feed; local-feed update passed
- [ ] Activation on three separate physical Macs; server limit was tested on one Mac

- [ ] Reordering without a mouse, with a VoiceOver-accessible alternative to drag
- [ ] Keep VoiceOver focus on the next row after deleting an item
