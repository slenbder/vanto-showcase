# Roadmap

What is done, what is in progress, and what comes after the first release.
Dates are not promised; the order is.

## Before 1.0

- [x] Queue for text, images, and files; sequential paste; reorder, delete, clear
- [x] Combine and Paste for text with a chosen separator
- [x] Settings: rebindable shortcuts, seven languages, Launch at Login
- [x] 14-day trial and license activation, validation, and deactivation
- [x] Automatic updates with Sparkle
- [x] Continuous integration on every pull request
- [x] Website in seven languages with a launch waitlist
- [ ] Developer ID signing and notarization of the release build
- [ ] End-to-end check of purchase, activation on up to three Macs, and refund
- [ ] First signed release published on the website and in [Releases](../../releases)
- [ ] First update delivered through the automatic updater

## After 1.0

- [ ] Reordering without a mouse, with a VoiceOver-accessible alternative to drag
- [ ] Keep VoiceOver focus on the next row after deleting an item

Have an idea? [Open a feature request](../../issues/new/choose).
